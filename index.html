它是怎么干活的

一个不断收敛的循环

就像一个人在用手机：看一眼 → 想一想 → 动一下 → 再看一眼。循环往复，直到任务完成。 每一步都会输出它在想什么（thought）和它要做什么（action）。

● CONVERGING

想一想

VisionClient · AgentPlan

04

再看一眼

01 / VISION

看懂屏幕

截图交给多模态大模型，识别当前是哪个 App、哪一页、该点哪里。

02 / ACT

替你动手

通过无障碍服务执行点击、长按、滑动、滚动、文字输入、返回 / 回桌面 / 多任务。

03 / LIVE

实时解说

每一步的「想法」和进度，实时显示在灵动岛（实况通知）上。

04 / CONTROL

随时可控

一键暂停 / 停止，停止立即生效；碰到付款、下单等操作会先停下来问你。

05 / MODELS

模型可换

内置豆包视觉、Qwen-VL，也支持任意 OpenAI 兼容的视觉模型，一套代码通吃。

06 / SECURE

密钥加密

API Key 用 EncryptedSharedPreferences 加密落盘，主密钥托管在 Android Keystore。

07 / PROMPT

自定义提示词

追加自己的做事习惯，例如「涉及付款先停下来问我」，优先级最高。

08 / PACE

智能节奏

按画面复杂度自动决定每步停多久，该快的时候快，该等的时候等。

09 / LEARN

自学习

每次任务结束自动复盘，攒下的经验下次自动带进提示词，越用越顺手。

隐私与安全

数据去向，由你决定

01

API Key 加密存储

使用 EncryptedSharedPreferences（AES256-SIV / AES256-GCM），主密钥由 Android Keystore 保管；设备不支持时自动降级并在设置页提示。

02

截图默认不落盘

屏幕截图只在内存中处理后发给你所选的模型服务；可在设置里按需开启本地留存，方便排查。

03

不经过第三方服务器

Orion 只与你配置的模型服务通信，没有中间账号系统，没有遥测上报。

常见问题

它会不会自己乱点？

它会不会自己乱点？

+

只在你说「开始」后才动手，任何时候都能暂停 / 停止；碰到付款、下单、发送消息这类不可逆操作会先停下来问你。初次使用建议从可逆的简单任务开始：打开 App、搜索、翻页。

提示「还没开启无障碍服务」怎么办？

+

去 系统设置 → 无障碍（辅助功能）→ 已安装的服务，找到 Orion 打开。小米 / 华为 / OPPO 等 ROM 可能还要额外允许「受限设置」，或对该 App 关闭电池优化，否则服务会被系统杀掉。

模型报 401 / 403 / 404？

+

基本都是 API Key 或 Base URL 填错。到「设置」核对 Base URL，改完点「测试连接」。豆包还需要先在控制台开通对应模型的接入点。

它看不懂屏幕 / 点错位置？

+

换更强的视觉模型（qwen-vl-max-latest、豆包 vision pro），或在「设置 → 自定义提示词」里加约束，例如「点击前先确认按钮上的文字」。

编译报 Unsupported class file major version？

+

JDK 版本太新，改用 JDK 17 并显式指定：-Dorg.gradle.java.home=/path/to/jdk-17。国内网络卡在下载依赖时，可在 gradle.properties 里加代理。
